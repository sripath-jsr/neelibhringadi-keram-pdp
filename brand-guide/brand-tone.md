# Brand Tone of Voice

How Kerala Ayurveda sounds. This guide covers the specific voice attributes, language rules, and copy patterns extracted from the Neelibhringadi Keram PDP (V2). Use it when writing any copy — product pages, ads, emails, social, packaging.

---

## 1. Voice Attributes

The brand voice has five attributes. Each exists on a spectrum — the right column shows where the brand sits and what it avoids.

| Attribute | The Brand Is | The Brand Is Not |
|---|---|---|
| **Confident, not boastful** | States facts plainly. Lets results speak. "Two wins. One formula." | Never uses superlatives ("best," "amazing," "revolutionary"), exclamation marks, or hype language. |
| **Precise, not clinical** | Uses specific numbers, timelines, and named ingredients. "Fall reduction in 2-3 weeks." | Never reads like a medical journal or a prescription. Stays conversational even when technical. |
| **Warm, not soft** | Sensory language, ritual framing, human testimonials. "A cooling sensation on the scalp within minutes." | Never sentimental, flowery, or vague. Warmth comes from specificity, not adjectives. |
| **Honest, not modest** | Acknowledges limitations. "Individual results may vary." Sets realistic timelines. | Never undersells. The brand is honest about what to expect, not apologetic about what it offers. |
| **Authoritative, not exclusive** | Speaks from 80+ years of practice. Uses Ayurvedic terminology naturally. | Never gatekeeps. Sanskrit/Ayurvedic terms are always accompanied by plain-language function. |

## 2. Language Register

The brand operates in two registers and shifts between them deliberately.

### Technical Register

Used for: ingredient descriptions, preparation methods, certifications, comparison data, FAQ answers.

**Characteristics:**
- Named herbs with Latin binomials: "Neeli (Indigofera tinctoria)"
- Named processes: "Taila Paka Vidhi," "kashaya (decoction)"
- Quantified claims: "4 primary herbs + triple-milk base + 15 supporting botanicals"
- Qualification language: "helps," "supports," "minimizes"

**Example from PDP:**
> Herbs are first made into a kashaya (decoction), then combined with the sesame oil base and kalka (paste). The mixture is heated on low flame, monitored by hand, until the water content fully evaporates and the herbal essence binds to the oil.

### Conversational Register

Used for: headlines, taglines, section labels, testimonials, application steps, closing CTA.

**Characteristics:**
- Short, punchy sentences. Often fragments.
- Sensory language: "cooling," "no heaviness," "no greasiness"
- Second person: "What you'll feel first"
- Ritual framing: "Warm, massage, leave, rinse"

**Example from PDP:**
> The honest sequence. Root strength comes before visible density.

### How to Switch

The two registers alternate — never within the same block of text, but across sections. A section heading uses conversational register; the body beneath it may shift to technical. The pattern:

```
[Conversational headline]
[Technical or mixed body]
[Conversational testimonial or callout]
```

**Rule:** Headlines invite. Body text informs. The headline makes you care; the body gives you the data to justify caring.

## 3. Sentence Style

### Length

- **Headlines:** 2-7 words. Maximum one clause. "Two wins. One formula." / "Go deeper." / "The honest sequence."
- **Sub-headlines / taglines:** 10-20 words. One main idea. "Helps minimize hair fall and supports new growth — starting within the first few weeks."
- **Body sentences:** 8-20 words. Plain construction. "The Neeli is working. Oil absorbs without heaviness."
- **Technical sentences:** Can run longer (20-35 words) but only when describing a process or ingredient. Never compound technical claims.

### Punctuation

| Mark | Usage |
|---|---|
| **Period** | Default sentence end. Used even in fragments. "Go deeper." not "Go deeper" |
| **Em dash (—)** | The brand's signature connector. Used to add a qualifier, a benefit, or a contrast. "Helps minimize hair fall and supports new growth — starting within the first few weeks." / "Bhringarajasava — fermented herbal brew for hair growth from within." |
| **Bullet (·)** | Inline separator for badges, labels, meta text. "HAIR FALL · HAIR GROWTH" / "Bengaluru · 6 weeks" |
| **Colon** | Rarely used. Only in structured data (ingredient lists). "Oil base: Sesame oil, Coconut oil" |
| **Exclamation mark** | Never used. Not once on the entire PDP. |
| **Question mark** | Only in FAQ answers and persona section header. "Is this for you?" / "When will I see results?" |
| **Ellipsis** | Never used. |
| **Quotation marks** | Only for direct customer quotes. |

### Capitalization

| Context | Rule |
|---|---|
| Headlines / H2 | Sentence case. "The honest sequence." not "The Honest Sequence." |
| Section labels | ALL CAPS with letter-spacing. "WHAT TO EXPECT" / "FIRST USE" |
| CTAs / Buttons | ALL CAPS with letter-spacing. "ADD TO CART" / "REORDER" |
| Badges | ALL CAPS. "HAIR FALL · HAIR GROWTH" / "IN STOCK" |
| Product name | Title case. "Neelibhringadi Keram" |
| Ingredient names | Title case. "Bhringaraja" / "Coconut Oil" |
| Body text | Sentence case, always. |

## 4. Word Choice Rules

### Preferred Vocabulary

| Instead of | Use | Why |
|---|---|---|
| Stops / Cures / Eliminates | Helps minimize / Supports / Reduces | Compliance. Ayurvedic products cannot claim to cure. |
| Revolutionary / Breakthrough | Classical / Proven / Traditional | Heritage positioning. Innovation is not the brand's story. |
| Buy now / Shop now | Add to Cart | Functional, not pushy. |
| Customers / Users | Name + City ("Priya M., Bengaluru") | Specificity builds trust more than anonymity. |
| Fast results / Instant | Within the first few weeks / 2-3 weeks | Honest timelines. |
| Natural / Organic (unqualified) | 100% natural herbs — no mineral oil, parabens, or synthetic fragrance | Specify what "natural" means. |
| Ancient wisdom / Secret formula | Classical formulation / 80+ year heritage formula | Ground Ayurveda in history, not mysticism. |
| Treatment | Ritual / Recovery system / Formula | The product is self-care, not medicine (even though it is Ayurvedic medicine). |
| Chemical-free | No parabens · No artificial fragrance · No mineral oil | Name what is absent instead of using vague claims. |

### Hedging Language

The brand consistently uses hedging verbs. This is not timidity — it is a deliberate compliance and trust strategy.

**Always hedge with:**
- "Helps" — "Helps minimize hair fall"
- "Supports" — "Supports hair growth," "Supports new growth"
- "Minimizes" — "Minimizes split ends," "Minimizes premature greying"
- "Promotes" — "Promotes regrowth"
- "Traditionally used to" — "Traditionally used to help minimise premature greying"

**Never use absolute claims:**
- "Stops hair fall" → "Helps minimize hair fall"
- "Grows new hair" → "Supports new growth"
- "Cures greying" → "Helps minimise premature greying"
- "Proven to work" → "Based on consistent use as directed"

### Sensory Language

The brand uses sensory words sparingly but precisely — to describe what the customer will physically experience, not to decorate.

**Allowed sensory words (from PDP):**
- Cooling, warm, earthy
- Heaviness / no heaviness / no greasiness
- Absorbs, penetrates, nourishes
- Texture, scalp, follicle

**Not allowed:**
- Luxurious (unless describing the ritual itself)
- Silky, glossy, shiny (cosmetic language — this is a medicinal oil)
- Exotic, mystical, sacred (orientalizing language)
- Fresh, clean, pure (too generic to mean anything)

## 5. CTA Language

### Primary CTAs

| CTA | Context | Note |
|---|---|---|
| ADD TO CART | Main action, buy bar, closing CTA | Always uppercase, always with price ("ADD TO CART — ₹315") in closing position |
| REORDER | Returning customer bar | Paired with price. Implies prior relationship. |
| VIEW CART | Post-add state | Paired with arrow icon. |

### Secondary CTAs

| CTA | Context | Note |
|---|---|---|
| + ₹225 | Bundle add-on button | Price is the CTA. No verb needed. |
| READ ALL 86 REVIEWS | Reviews section | Specific number, not "Read more reviews." |
| Go deeper. | Accordion section header | Serif italic. Invitation, not instruction. |

### CTA Rules

1. **Primary CTAs are always uppercase, Work Sans, 700 weight, letter-spaced.** They are functional and direct.
2. **Secondary CTAs can be softer** — serif italic ("Go deeper."), or just a price ("+ ₹225").
3. **Never use urgency language** in CTAs. No "Buy now," "Don't miss," "Limited time."
4. **Include the price in the CTA** when the action involves spending money. "ADD TO CART — ₹315" not just "ADD TO CART" (the closing CTA includes price; the sticky bar separates them with a divider).
5. **Include a count when available.** "READ ALL 86 REVIEWS" not "Read reviews."

## 6. Testimonial Voice

Customer quotes have their own sub-tone within the brand voice. They are curated to sound like real people while reinforcing brand messaging.

### Testimonial Characteristics

- **First person, past tense observation.** "Less hair in the shower drain by week three." Not "This product is great!"
- **Specific detail.** Timeframes ("week three," "four months in"), body parts ("temples," "shower drain"), and named observers ("my barber noticed").
- **Understated.** "That was the first sign it was working." Not "I'm amazed!" or "Life-changing!"
- **Process-aware.** "Consistent use was the key. It's a recovery system, not a quick fix." Customers echo the brand's patience messaging.
- **Sensory.** "The cooling on day one is real." / "The earthy smell has grown on me. No heaviness."

### Attribution Format

Always: **"Quote text." — First Name Last Initial., City**

Examples:
- "Less hair in the shower drain by week three." — Priya M., Bengaluru
- "The cooling on day one is real — I wasn't expecting it." — Ananya R., Mumbai

**Rules:**
- Always include city. It makes the testimonial feel locatable and real.
- Use first name + last initial. Full last names feel corporate; first name only feels fake.
- Timeframe badges are separate from the quote ("Less Fall — Week 3", "Growth Visible — Month 3").

## 7. Do's and Don'ts

### Do

- **Do** let the product's age and process be the confidence. "Some formulas don't need improving."
- **Do** use em dashes to add qualifiers and benefits naturally.
- **Do** give specific numbers over vague claims. "86 reviews" not "many reviews." "2-3 weeks" not "soon."
- **Do** name the ingredients and their functions. Every hero ingredient earns a role badge (Growth, Recovery, Strength, Nourish).
- **Do** set honest expectations. "Root strength comes before visible density."
- **Do** use the customer's own language in testimonials. Observation over enthusiasm.
- **Do** include both the common name and Latin binomial for key herbs on first mention.
- **Do** frame the product as a ritual. "Thirty minutes, three times a week. Warm, massage, leave, rinse."

### Don't

- **Don't** use exclamation marks. Ever.
- **Don't** use superlatives (best, most, ultimate, #1).
- **Don't** create urgency or scarcity ("Only X left," "Sale ends soon").
- **Don't** promise cures. Always hedge. "Helps" and "supports" are your verbs.
- **Don't** use the word "ancient" — it sounds exotic. Use "classical" or "80+ year."
- **Don't** write paragraphs when a sentence will do. If the headline says it, the body should not repeat it.
- **Don't** use filler adjectives (amazing, incredible, wonderful, fantastic). If you need an adjective, make it sensory or specific.
- **Don't** address the reader as "you" excessively. Once per section is enough. Let the product speak for itself.
- **Don't** apologize or disclaim defensively. Disclaimers should be factual and calm ("Individual results may vary"), not anxious.
- **Don't** use emoji in any product copy. The visual system uses icons; the text does not need decoration.

## 8. Tone Shifts by Context

The overall voice stays consistent, but the emphasis shifts depending on where the copy appears.

| Context | Tone Emphasis | Example |
|---|---|---|
| **Above the fold** | Confident + precise. Lead with the benefit, back with credentials. | "Helps minimize hair fall and supports new growth — starting within the first few weeks." |
| **Pricing zone** | Factual + anchored. Per-use math, rating, delivery logistics. | "~₹10.50 / USE · ~30 USES" |
| **Mechanism sections** | Warm + technical. Explain how it works without losing the human. | "A cooling sensation on the scalp within minutes. The Neeli is working." |
| **Timeline / expectations** | Honest + patient. Set real expectations. | "The honest sequence. Root strength comes before visible density." |
| **Testimonials** | Observational + specific. Real people noticing real changes. | "Started using it for early greying at 28. Four months in, fewer new greys." |
| **Ingredients** | Technical + structured. Named functions, role badges, Latin names. | "Bhringaraja — Supports hair growth. Activates follicles and increases scalp circulation." |
| **Comparison** | Factual + confident. Let the data do the arguing. | "11-day classical extraction" vs. "Machine-mixed, same day" |
| **Closing** | Quiet + resonant. Return to the heritage anchor. | "Some formulas don't need improving. This is one of them." |
| **Safety / FAQ** | Calm + direct. No alarm, no evasion. | "For external use only. Always patch-test before first application." |
